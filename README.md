# TMX AI

Statische Website (HTML/CSS/JS, keine Server-Abhängigkeiten, keine externen Dienste beim Laden).

- Lokal starten: `python -m http.server 8080` im Ordner, dann http://localhost:8080
- Inhalte bearbeiten: `/admin/` (GitHub-Token mit „Contents: Read and write“ nur für dieses Repo)
- Kontaktformular: kostenlosen Web3Forms Access Key im Admin unter „Allgemein & Kontakt → Kontaktformular“ eintragen.
